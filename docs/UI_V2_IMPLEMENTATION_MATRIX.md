# BlueLink V2 界面实施矩阵

本文件把 `UI_IMPLEMENTATION_SPEC_V2.md` 中的 30 个原型页转换为可执行验收项。状态只允许：

- `TODO`：尚未实现。
- `ACTIVE`：正在实现，尚未验收。
- `DONE`：功能、状态和基准截图均已验收。
- `SYSTEM`：由操作系统提供，应用只验证调用参数和权限。

## 截图基线

- Windows：1600×1000，另验 125%/150% DPI 与 1180×720 最小窗口。
- Android：412×915 dp，另验 360–600 dp 和字体缩放 1.0–1.3。
- `DONE` 必须同时满足：真实入口、完整状态、交互行为、无横向滚动、人工视觉确认。
