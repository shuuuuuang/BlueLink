## 2026-09-13：多架构构建与 Windows Portable

## 2026-09-13：生产 USB 文件通道改为 WPD/MTP

同一物理手机的双向文件共用 FIFO 队列，后续文件显示“排队等待”；暂停队首保留槽位，取消等待项跳过该项，取消队首须等本地流退出后接续。不同手机使用独立调度器；文件探测、清理与数据流共用访问门。外部设备忙仅在打开/创建流前有界退避，部分写入不自动重放。闪电由认证会话对应的目录证明和 WPD 就绪状态决定，名称/MAC 不建立信任。公共目录只保存 BLM1 加密中转文件，单次密钥经加密蓝牙发送。

## 已知限制

1. 当前 Android 产物使用 debug 签名，Windows EXE/安装包没有商业代码签名证书；仅适合内部验收。
2. 断点数据可跨进程恢复，但发起方仍需在重连后点击重试；同 ID 重试会从接收方连续已提交 extent 继续。超限 Offer 在活动会话内保留约 30 秒，过期需对端重试。
3. 流控仍为逐 64 KiB 块确认；大文件吞吐量受经典蓝牙和 stop-and-wait 往返影响。
4. 当前安全协议为项目自有 BTX/1.1；正式高安全等级发布前仍需独立密码协议审计。
5. Android 当前以 API 36 的 USB 真机验收；模拟器禁止运行。多设备、真实蓝牙中断、完整逐屏/语言矩阵仍未通过，部分 Debug 内存场景只证明组件布局。
6. Windows 使用 WiX Burn + WPF 安装 UI；23个原型场景已有150% DPI原生组件范围证据，100%/125% DPI和真实安装矩阵仍待验收。
